Bug Fixes Tags that have a key but no value now display and save correctly in the query builder's tag filter (previously they appeared as key:null and could save an incorrect value). Fixed several bugs that may block deleting users when the "Remove users from Opal when deprovisioned" setting is turned on. Improved Scrolling and typing in the campaign review inbox is significantly smoother for reviewers with many assigned items.
