Added The PagerDuty connector can now import the account-level Owner role and its assignment as an import-only resource (behind a feature flag), making it visible in user access review campaigns. Because PagerDuty provides no API to modify the Owner role, grant and revoke attempts on it report a clear "operation unsupported" status instead of an internal error Added "Wait Time" column to the "Admin" tab of the "Requests" page Bug Fixes Fixed resource deletion silently failing to delete anything on large syncs
