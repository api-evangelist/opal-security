Added Added support for GCP billing accounts: you can now import billing accounts into Opal and request access to them, including roles such as Billing Account Administrator and Billing Account Viewer Added support for custom billing roles on GCP billing accounts, in addition to the predefined ones Admins can now configure allowed callback URLs for MCP OAuth in org settings (searchable as "MCP OAuth callback URLs") The audit log now records which reviewer denied a request, matching what is already recorded for approvals Improved The Opal MCP server now returns legible error messages to MCP cli
