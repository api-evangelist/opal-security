Added Google Groups connections now support "Auto-import all" (enabled per org via feature flag) MCP (End User): get_resource_reviewers and get_resource_request_configurations are now available on the end-user MCP endpoint, letting agents preview reviewers and request constraints (max/recommended duration, MFA, support-ticket, auto-approval, requestable flag) before calling create_request Improved Reviewers can now rate Paladin's access request decisions from Slack using a form that shows their answer, with optional reasons and a comment; ratings can be changed or removed later
